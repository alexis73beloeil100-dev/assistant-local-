LICENCE DE L'ASSISTANT LOCAL
============================

Ce logiciel est libre. Vous pouvez l'utiliser, le copier, l'etudier, le
modifier et le redistribuer.


CE QUE VOUS RECEVEZ ICI
-----------------------

Le programme que vous installez est distribue sous licence MIT.

Jusqu'au 23/08/2026 il se transmettait sous GPLv3, parce qu'il integrait la
bibliotheque openrgb-python, elle-meme sous cette licence. Cette bibliotheque
a ete remplacee par du code ecrit pour ce projet : l'assistant parle
directement au serveur OpenRGB, par son protocole reseau.

Le programme n'integre donc plus aucun composant qui impose sa licence a
l'ensemble.


LE CODE ECRIT POUR CE PROJET
----------------------------

Les fichiers ecrits pour l'Assistant local sont publies par leur auteur sous
licence MIT. Vous pouvez les utiliser, les modifier et les redistribuer, y
compris dans un logiciel proprietaire, a la seule condition de conserver la
mention de copyright et le texte de la licence.


LES AUTRES COMPOSANTS
---------------------

Le logiciel embarque une trentaine de bibliotheques tierces : reconnaissance
vocale, calcul, lecture d'images, et les bibliotheques CUDA de NVIDIA qui
representent l'essentiel de sa taille. Chacune garde sa propre licence.

Le detail complet, composant par composant, est dans le fichier
LICENCES-TIERS.md installe a cote du programme.

OpenRGB n'est PAS livre avec ce programme. Le pilotage de l'eclairage RGB
demande de l'installer separement, depuis :

    https://openrgb.org

C'est un logiciel libre distinct, sous GPLv2, edite par un tiers.


ABSENCE DE GARANTIE
-------------------

Ce programme est fourni sans aucune garantie, dans la mesure permise par la
loi applicable. L'auteur ne peut etre tenu responsable des dommages qui
resulteraient de son utilisation.


CE QUE LE LOGICIEL NE FAIT PAS
------------------------------

Rien de ce que vous dites ou de ce qui se trouve sur cette machine n'est
envoye ailleurs. Le modele de langage, la reconnaissance vocale et la
synthese fonctionnent entierement en local. Il n'y a aucune verification
automatique de mise a jour, aucune telemetrie, aucun compte.

La seule connexion sortante a lieu si vous demandez explicitement le
telechargement des composants (moteur d'IA et modeles de voix), sur l'ecran
propose a la fin de l'installation.
