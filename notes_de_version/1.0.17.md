**Les demandes Unreal courantes ne dépendent plus du modèle.** Lancer les tests automatisés, lancer une partie dans l'éditeur (PIE), compiler, ouvrir Unreal, lire le dernier plantage ou les journaux, faire le point sur le projet : l'application lance l'outil elle-même et affiche son résultat. Même dicté de travers (« lance-moi un test PI »).

**Les tests d'Iron Fall sont trouvés.** L'outil lit les tests écrits dans le code du projet au lieu de chercher des tests nommés « Project ». Si aucun ne tourne, il affiche l'erreur d'Unreal (projet pas compilé, par exemple).

**Plus de « sur quel projet ? ».** Le dernier projet ouvert dans Unreal est pris, et le modèle connaît son nom.

**Tu vois ce qu'il fait.** Sous chaque outil : ce qu'il a reçu et ce qu'il a rendu.

**Plus rapide.** Pas de réflexion silencieuse pour une question simple ; elle reste pour le code.

**Moins de ratés.** Plus de bulle vide, plus de réponse « je suis prêt, dis-moi », plus de demande refusée comme « texte du panneau ».
