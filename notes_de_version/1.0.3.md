Assistant vocal et textuel qui connaît cette machine. **Rien ne sort du PC** : le modèle de langage, la reconnaissance vocale et la synthèse tournent tous en local.

## Installation

Télécharge **Installer_AssistantLocal.exe** ci-dessous et lance-le. C'est tout : ni Python, ni dépendance à installer, tout est embarqué.

Le fichier pèse **1,1 Go** — l'essentiel étant les bibliothèques CUDA et les modèles qui font tourner l'assistant hors ligne.

Windows peut afficher un avertissement SmartScreen : l'installateur n'est pas signé par un certificat commercial. « Informations complémentaires » puis « Exécuter quand même ».

## Vérifier le fichier

Empreinte SHA-256 de l'installateur :

```
0f0c7efaaf4f330bb4da1097060c7ae53f9421d7c5addb71f9236f343fe05771
```

À contrôler avant de lancer, dans PowerShell :

```
Get-FileHash .\Installer_AssistantLocal.exe -Algorithm SHA256
```

Si l'empreinte affichée diffère de celle-ci, le téléchargement est incomplet ou altéré : ne lance pas le fichier.

## Nouveautés de la 1.0.3

- L'éclairage RGB n'accuse plus le serveur OpenRGB pour une erreur venue du code : un défaut interne s'annonce désormais comme tel, avec l'erreur réelle, au lieu de « Serveur OpenRGB injoignable ».
- L'installateur efface les fichiers disparus d'une version à l'autre au lieu de les laisser traîner.
- La mention de copyright nomme l'auteur.

## Configuration requise

Windows 10 ou 11, 64 bits. Un GPU NVIDIA accélère nettement l'assistant, sans être obligatoire.
